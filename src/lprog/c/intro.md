
# Le langage C

Le C est le premier langage de programmation que vous allez voir en prépa, et il vous accompagnera pour le reste de vos deux année.

C'est un langage impératif, très bas niveau, dont nous allons bientôt voir les spécificités.

Ce cours sera fortement inspiré de celui que vous pouvez retrouver [ici](https://www.w3schools.com/c/c_intro.php). Bien qu'en anglais, il vaut le coup d'oeuil, n'hésitez pas à aller y faire un tour en complément.
