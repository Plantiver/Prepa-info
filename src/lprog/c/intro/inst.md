## Installation
### Vérifier si GCC est déjà installé

Pour travailler avec le langage C, nous aurons besoin d'un programme spécifique, gcc, qui nous permettra de compiler notre code en langage machine. Nous devons donc nous le procurer.

Par chance, sur la majorité des machines, gcc sera déjà installé, et nous pourrons l'utiliser directement. Pour tester si vous faites parties des heureux.ses élu.es, entrez dans votre terminal:
```$ gcc --version```

Vous devriez obtenir:
```
gcc (GCC) 16.1.1 20260430
Copyright (C) 2026 Free Software Foundation, Inc.
This is free software; see the source for copying conditions.  There is NO
warranty; not even for MERCHANTABILITY or FITNESS FOR A PARTICULAR PURPOSE.
```

Si c'est le cas, ou alors que vous obtenez un messsage similaire avec juste un numéro de version différente, c'est que vous avez déjà gcc, vous pouvez passer à la page suivante.

Pour ceux qui restent, vous avez sans doute obtenu un message du genre:
```bash: gcc: command not found```
Cela signifie que nous allons devoir installer manuelement gcc.
